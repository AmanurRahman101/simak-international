# SIMAK International Website

Static marketing site for **SIMAK International** - a Dhaka-based trading company.

## Stack

- HTML
- CSS (`css/style.css`)
- Vanilla JavaScript (`js/main.js`)

No React, Tailwind, or animation libraries.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Landing |
| `about.html` | About SIMAK |
| `services.html` | Services |
| `contact.html` | Contact |

## Deploy

Published via GitHub Pages from the `main` branch root.
